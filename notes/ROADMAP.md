# Roadmap

The C++ core is shared by the R and Python packages. Later work can use the same library.

## Other applications

The same likelihood applies to other repeated Likert panels, including election-study panels, once the file is in the long person-wave layout the packages already read.

## Stata

A Stata front end can call the same core and return the unconstrained coefficients together with a covariance estimator.

## Bayesian estimation

A later version can place a prior on the unconstrained coefficients and sample the posterior with the same data layout and the same recursion.
